Paket deploy statis SIF POINT BATARA

1. Ekstrak ZIP. Pastikan index.html ada di root folder SIF_POINT_BATARA_Vercel.
2. Unggah folder tersebut melalui https://vercel.com/drop, atau jalankan vercel dari folder ini.
3. Jika memakai pengaturan proyek manual: Framework Preset Other, Build Command kosong, Output Directory default (root).
4. Uji halaman utama, video, gambar, font, peta, dan semua menu setelah deploy.

Ini prototipe statis. Form permintaan data/mitra tidak menyimpan ke database, peta dasar memerlukan internet, dan data Google Sheets belum memiliki konfigurasi aktif. Paket ini tidak menambahkan backend.
